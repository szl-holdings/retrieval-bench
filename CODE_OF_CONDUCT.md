# Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, experience level, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our standards

Welcoming language, respect for differing viewpoints, constructive criticism, and empathy are expected. Harassment, trolling, insults, and publishing private information without permission are unacceptable.

## Enforcement

Report incidents privately via GitHub Security advisories or CODEOWNERS maintainers. Adapted from the Contributor Covenant, version 2.1.
